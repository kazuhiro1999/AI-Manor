# food_composition_8th_2023.csv — 同梱の食品成分表（ADR-019 §4 追補）

## 出典

文部科学省「日本食品標準成分表（八訂）増補 2023 年」**第2章 本表**。

- 配布元: 文部科学省ウェブサイト（食品成分データベース／日本食品標準成分表のページ）
- 元のファイル形式: Excel（本表のみで約 1.9MB）
- 版: `8th-2023`（`chef_food.source_version` の値。以後 `manor` 内で版を指すときの表記）

## 利用条件の要旨

文部科学省が公開する統計・データは「政府標準利用規約」に基づき、**出典を明記すれば**
複製・公衆送信・翻案（二次利用）が認められている（商用・非商用を問わない）。本ファイルは
その二次利用として、本表の数値をそのまま抜き出し正規化した写しである。**最終的な利用条件は
必ず配布元ページの表記を確認すること**（本項は要旨であり、法的な確認を代替しない）。

## 正誤表

文部科学省は本表の公開後に正誤表（訂正）を出すことがある。**本ファイルは正誤表を
当てていない**——2026-09-13 時点で `home/food/` を確認したが正誤表の Excel は
見当たらず、当てる作業（差分の反映）も今回は行っていない。訂正を反映したい場合は、
主人が正誤表の内容を確認したうえで、下記の「作り直し方」の本表 Excel 側に手当てしてから
書き出し直すこと（`manor` は正誤表を自動で当てる仕組みを持たない）。

## 列（9列だけ）

| 列 | 中身 | 備考 |
|---|---|---|
| `food_code` | 食品番号 | 成分表の索引番号ではなく食品番号（5桁） |
| `food_group` | 食品群 | 食品番号の先頭2桁と同じ値のことが多い |
| `name` | 食品名 | 空白の連続を半角1つに畳んだだけ（語彙の正規化・下ごしらえ語の削りは掛けていない。名寄せは `chef_food_alias` と部分一致で別に行う） |
| `kcal` | エネルギー（kcal） | kJ 列ではなく kcal 列 |
| `protein_g` | たんぱく質（g） | 「アミノ酸組成による」ではなく素の値。未測定は空欄 |
| `fat_g` | 脂質（g） | 「脂肪酸のトリアシルグリセロール当量」ではなく素の値。未測定は空欄 |
| `carb_g` | 炭水化物（g） | 「利用可能炭水化物」ではなく素の値 |
| `salt_g` | 食塩相当量（g） | |
| `refuse_pct` | 廃棄率（%） | 廃棄率が無い食品は 0 |

`Tr`（微量）・`-`（未測定で計算できないもの）は既に数値化済み（`Tr`/`-` → 0、
括弧つきの推定値は括弧を外した値）。空欄は「成分表がそもそも値を持たない」ことを示す
（未測定として `NULL` のまま扱う。0 とは意味が違う）。

`per`（100gあたり）・`source_version`（版）は列に持たない——どちらも表全体で1つに
決まる値なので、取り込み時の引数・定数で足す（`nutrition.PER_100G`・
`import_food_table(source_version=...)`）。

## 作り直し方（版を上げるとき）

1. 文部科学省の公式サイトから新しい版の本表 Excel を落とし、`home/`（git 管理外）に置く
2. 取り込む: `uv run manor chef food import <落とした Excel の道> --source-version <新しい版>`
3. 書き出す: `uv run manor chef food export`（引数を省略すると本ファイルの場所へ書く）
4. 差分を確認してコミットする（`git diff` で行数・値の変化を見る）

`manor chef food import`（引数なし）は本ファイルを読む。版を上げていない普段の取り込みは
何もしなくてよい——`manor init` が `chef_food` の空の home へ静かに取り込む
（`docs/design/ADR-019_nutrition_from_composition_table.md` §4「同梱 CSV」参照）。
