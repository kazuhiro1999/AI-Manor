# ADR-022: 名寄せ・換算の未解決を Claude（Web 検索）にまとめて調べてもらう

- 状態: **採択・実装済み**（2026-09-25）
- 関係: ADR-019（食品成分表。D2 の第三段「`claude -p` で名寄せの下書き」をここで実現し、換算まで広げた）、
  ADR-021（お供。取り込んだレシピの栄養値が埋まらないと候補にならない）、ADR-020（レシートの `claude -p` の作法）

## 1. 何が困っていたか

主人「ほうれん草のおひたしを追加したら、名寄せできていない材料に『ほうれん草（1袋）』が入った。一般的なものは
Claude の Web 検索で解決する経路を足せないか。いちいち Claude Code で報告して直してもらう手間がある。
ただし Claude のセッションを何度も起動しなくて済む経路があるなら、そこに足してほしい」。

実際の原因は名寄せ（名前）ではなく**換算**だった——「ほうれん草」は成分表に当たるが、`[units.piece."袋"]` に
ほうれん草の行が無く「1袋 = ? g」が分からない（`no_piece`）。この種類は設定画面の「食品を選ぶ」では直らず、
`lexicon.toml`（①）を書き換えるしかなかったので、毎回執事への報告が要った。

## 2. 決めたこと

### D1 覚えた換算 `chef_food_unit`（DB。②）
- 列: 材料名（正規化）・単位・1 単位あたりの g・`confidence`（`manual`／`llm`）・出典 URL・根拠の一文。
- 推定が引く順は **manual → lexicon → llm**（`nutrition.tables_for`）。主人が画面で入れた値が一番強く、
  Claude の値は lexicon に無いときだけ効く。
- 設定 → 食品の名寄せ: 単位の未解決の行に「ほうれん草 1袋 = [ ] g」の入力（manual）。「覚えた換算」の一覧に
  出典リンクつきで並び、外せる。

### D2 調べ方（`staff/chef/food_resolve.py`）
- 対象: `no_piece`／`unknown_unit`（1 単位の重さ）と `no_food`（成分表のどの食品か）。`no_amount` は渡さない。
- **未解決の一覧を1回の `claude -p` に渡す**（上限 `max_items`）。道具は WebSearch・WebFetch だけ、家の文脈
  （CLAUDE.md・hook）は読ませない（`--setting-sources ""`・空のフォルダで起動）、出力は JSON だけ。
- 重さは Web で一般的な値を探させ、**出典 URL** を添えさせる。範囲外（`grams_min`〜`grams_max`）は捨てる。
- 食品は**こちらで成分表を検索した候補の中から選ばせる**（番号を作らせない——数字の出どころは成分表だけ、
  という ADR-019 の約束）。候補は名前そのものに加え、名前の一部（後ろを残す削り方から）でも引く
  ——「花かつお」は成分表では「かつお 削り節」。
- 答えは `chef_food_unit`／`chef_food_alias` に `llm` で書く。**manual は上書きしない。** 書いたら全件を推定し直す。

### D3 聞き直しの間
`chef_food_resolve_attempt` に調べた記録を残し、**調べて分からなかったもの**は `retry_days`（7 日）聞き直さない。
claude が呼べなかった・時間切れ（`failed`）は数えない——次の機会にすぐ聞き直す（ログイン切れの日に止まらない）。
主人が画面で外した換算も「分からなかった」扱いで間を置く（外したそばから Claude が入れ直さない）。

### D4 いつ走るか（セッションを何度も起動しない）
- **レシピの登録・編集の直後に、背景で自動**（`[nutrition.claude_resolve].auto`）。1 本のスレッドが回し、
  走っている間の依頼は「もう1周」の印にまとめる——続けて何本登録しても Claude は多くて2回。未解決が無ければ呼ばない。
- 設定 → 食品の名寄せ の「Claude に調べてもらう」（同じ作業係。3 秒おきに様子を見て、終わったら一覧を読み直す）。
- CLI `manor chef food resolve`（前で1回。夜勤や手元の確かめ用）。
- 夜勤（大きな対話のセッション）には載せなかった——「一覧を渡して JSON をもらう」だけの用途には重すぎ、
  登録から翌朝まで栄養値が空になる。
- 環境変数 `MANOR_CLAUDE_RESOLVE=off` で自動を止める（試験は必ず止める）。

## 3. 実測（2026-09-25。本番 DB の写し）
「ほうれん草 1袋」→ 200 g（出典つき）を **13 秒・1 回の呼び出し**で返し、おひたしの解決率が 100% になった。

## 4. 範囲外
- 分量が書かれていない材料（`no_amount`）。
- 換算を `lexicon.toml`（①）へ書き戻すこと——家の値は DB（②）に置く。広く効く値だと分かったら執事が lexicon に移す。
