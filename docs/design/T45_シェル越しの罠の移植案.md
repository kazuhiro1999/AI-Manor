```
# シェル越しの罠を避ける

## 1. まずこれ — 内容を shell 層に通さない
バックスラッシュ・日本語・`$`・引用符・`{}` を含む「内容」は、shell を経由させない。
Edit / Write ツールで直接書く。

## 2. やむを得ず shell を通すとき
- ヒアドキュメントの終端は必ずクォート（`<<'EOF'`）
- 置換は黙って失敗する。書いたあと grep で検算する
- 行数スプライス（head -N / tail -n +M）は直前に行番号を取り直す

## 3. 出力が化けたら、中身を疑う前に経路を疑う
grepは正しく出るのにprintが化ける、ということが起きる。コンソールの問題であって
ファイルの中身は無事なことが多い。
```
