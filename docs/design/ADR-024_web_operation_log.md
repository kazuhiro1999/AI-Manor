# ADR-024: Web の操作ログ（いつ・だれが・何をしたか）

- 状態: **採択・実装済み**（2026-09-25。方針は主人の裁定）
- 関係: ADR-005（Web の門）、ADR-014（利用者。D3 見ている人）、ADR-017（端末の鍵・送信元の区分）、ADR-006 §3（`run` 表）
- 実装: `src/manor/web/oplog.py`、`web/app.py` の `_OpLogMiddleware`、`web/_common.open_conn`、`manor web log`

## 1. 何をしたいか

主人以外（同居予定の方）も Web を使うようになるので、**Web の上で人が何をしたか**
（レシピを足した・来た・対話モードで話した）をサーバ側に残したい。

## 2. 調べて分かったこと（2026-09-25）

- 記録に「だれ」が無い。`task_event.actor`・`decision.actor` は `web`/`cli`/`butler` という経路の名前だけで、
  約 90 ある Web の書き込みの口のうち、誰がやったかを残すのは 3 つだけ。
- Web の要求の記録が無い（uvicorn の出力はランチャーが捨てている。送信元の区分は毎回出すが残さない）。
- manor が自分で動いた分（夜勤・`run` 表・夜勤ログ）はすでに残っている。

## 3. 決めたこと

### D1 軽く作る（主人の裁定）
- **本人確認はしない。** 主な使い手は主人と同居人の2人。「だれ」は画面で選んでいる人（ADR-014 D3。自己申告）で足りる。
- **DB には何も足さない。** テキストのログで残っていればよい。見るのは運用側のコマンドで、画面は作らない。
- manor が自分で動いた分は今の記録のまま（厳密にしない）。

### D2 置き場と形
- `home/logs/web-YYYY-MM.log`。月ごと・1行1件・追記だけ。**12 か月より古い月は消す**（月が変わって最初に書くとき）。
- 1行 = `時刻 user=<id>(<呼び名>) ip=<印> zone=<区分> <方法> <経路> <結果> <ms> <書いた表…>`。
  端末鍵なら `device=<id>(<名前>)` が前に付く。
- 書けなくても操作は止めない。

### D3 何を残すか
- **GET 以外の要求は全部**（`/api/v1/`。ログインの成否もここに入る）。ペアリング中の端末の問い合わせ（`pair/poll`）は除く。
- **GET でも DB を書いた・背景の仕事を起こしたものは残す**（レシピ帳を開くと YouTube の同期が走る、など）。
- ふだんの GET は残さない代わりに、同じ人・同じ端末から **30 分あいて来たら `visit`** を1行。
- 対話モードは `POST /face/talk/open`・`/face/talk`（1往復）・`/close` の行で分かる。**会話の中身は残さない**。
- 背景の仕事は、起こした要求の行に `bg:food_resolve` のように添え、終わったら `bg food_resolve … cost=$… 秒` を1行
  （食材の自動調べ・YouTube の同期。レシートの読み取りは起こした印だけ）。

### D4 何を書き換えたかは自動で拾う
Web の DB 接続は全部 `open_conn` を通るので、そこで SQLite の trace を付け、要求のあいだに実行された
INSERT／UPDATE／DELETE の**表の名前だけ**を拾う（`+` 追加・`~` 更新・`-` 削除。値は捨てる）。口ごとに書き足さなくても、
新しい機能もそのまま残る。

### D5 残さないもの
本文・クエリ文字列・会話の中身・秘密の値・**生の IP**。IP は `home/web-secret` を鍵にした HMAC の先頭6桁
（同じ端末なら同じ印、元へは戻せない。IPv4 の素のハッシュは総当たりで戻せるので鍵を使う）。サーバ機そのものは `local`。
tailscale 経由は転送元ではなく元の端末の IP を使う。

### D6 見方
`manor web log`（今月の末尾 50 行）。`--month 2026-09`・`--user u2`・`--grep /kitchen/recipes`・`-n 0`（全部）・`--months`。

## 4. 範囲外
- 本人確認（人ごとのパスコード等）。必要になったら別に決める。
- CLI・夜勤・Slack からの操作の記録（今の `run` 表・夜勤ログのまま）。
- `task_event.actor` 等で Web の操作が `butler` と記録される箇所の修正。
