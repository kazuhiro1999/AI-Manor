# ADR-013 — 「フォルダを触らせない」の総点検（5g）

日付: 2026-09-05 ／ 状態: 採択 ／ 決めた人: 執事（Opus）

## 1. 背景

主人の方針（ROADMAP 11-1）:「インターフェースは基本的に Web アプリ経由とし、フォルダの中を
ユーザーが操作しなくてよいようにする」。

執事が書き込みコマンド **59 件**を機械で洗い、Web の口と突き合わせた（2026-09-05）。
台所・家事・家計・秘書・タスク・裁定・ルール・タスクの種類は画面から届いていた。
**届かないものが3つ**残っていた。

主人の指示:「プロジェクトの作成や Tailscale の件はアプリからできるようにすべきです」。

| # | 届かないもの | なぜ困るか |
|---|---|---|
| 1 | プロジェクトの作成・変更 | 初回セットアップ以外に作る道が無い。自律レベルや優先度も変えられない |
| 2 | `require_passcode` | **Tailscale の導入手順が「config.toml に手で追記」と指示していた**——方針への正面からの違反 |
| 3 | メモ（note）の追加 | 画面から残せない |

`agent sync`・`import-v1` は端末のみのままでよい（保守の道具であって、日々の操作ではない）。

## 2. 決定

### D1 プロジェクトの作成・変更を画面から

- `POST /api/v1/tasks/project`（作成）／`POST /api/v1/tasks/project/{ref}`（変更）
- 置き場は「計画 → プロジェクト俯瞰」。一覧に「＋ プロジェクト」、各行から編集
- 変えられるもの: 名前・種別・優先度・**自律レベル**・状態・期限・次の一手
- **コード（`P1` 等の記号）は作成時のみ。** あとから変えると、他から参照している記号が
  すべて外れる。画面でもそう伝える（入力欄を出さない）
- 自律レベルの選択は**セットアップと同じ語彙**を使う（`web/src/app/setupChoices.ts` の
  `PRESET_LABEL_KEY`）。同じものに2つの言い方を作らない

### D2 `require_passcode` を画面から（Tailscale の手編集をなくす）

設定画面のパスコード節に「外部からのアクセスにパスコードを要求する」を置く。

- **パスコードが未設定のまま on にできない。** できてしまうと主人が自分を締め出す
  ——API 側で拒否し、画面でも押せないようにする（両方でやる。画面だけだと API から抜ける）
- **off にするのは、ループバック以外で待ち受けている最中は拒む**（外に晒したまま鍵を外せない）
- `src/manor/extensions/tailscale.py` の `install_steps` から「config.toml に追記」を消し、
  「設定画面で入れてください」に書き換える

### D3 メモの追加を画面から

- `POST /api/v1/tasks/note`。置き場は「AIの進行中 → 伝達」（`board.notes` を出している所）
- 宛先（`about`）は任意。本文だけで残せる

### D4 passcode は秘密の置き場へ。**値そのものを保存しない**（2026-09-05 追補）

主人の指示「パスコードの置き場も修正しておきましょう」。

- 置き場を `home/config.toml` から `~/.manor/secrets/web.json` へ移した（ADR-009 D4 の線に戻す）
- **保存するのは塩つきのハッシュ**（PBKDF2-HMAC-SHA256・20万回）。画面は元から
  「ここは書くだけで、現在の値は表示しません」と言っており、**読み出す必要がどこにも無い**
  ——ならば復元できない形で持つ。主人が他所と同じ言葉を使っていても、このファイルからは辿れない
- **`web_config.get_passcode()` は消した。** 平文を返す口が在る限り、いつか誰かが呼ぶ
- 移行は起動時に冪等に走る。順番は**足す → 確かめる → 消す**——確かめる前に消すと、
  書き込みが失敗していたときに主人が自分のアプリへ入れなくなる。どこで落ちても平文は残り、
  照合も「ハッシュ → 平文」の順に見るので、移行が半分でも入れる
- **置き場は home ごとに分けない。** 分ければ home が2つあるとき混ざらない代わりに、
  manor のフォルダを動かした瞬間に passcode を見失う——締め出しのほうが実害が大きい

## 3. やらないこと（今回）

- ~~パスコードの置き場を移すこと~~ → **主人の指示で同日に実施した（下記 D4）**
- 画面から届かないままにするもの: `agent sync`・`import-v1`（保守の道具）
- バックエンドが返す分類ラベルの多言語対応（台所・家事・秘書の一部。5h の既知の穴）
