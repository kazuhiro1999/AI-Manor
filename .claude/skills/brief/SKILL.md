# /brief — 執事ブリーフィング

止まらずに最後まで走る。**途中で主人に確認しない。** 判断が要るものは `manor decision ask` へ積む。

## 手順

1. **読む**（並列でよい）
   - `manor active` / `manor check` / `manor milestone list` / `manor project list`
   - `butler/INTENT.md` の差分検知チェックリストを全項目走査する
2. **予定を見る**
   - 秘書（secretary）の `manor sec agenda --days 7` で今週の予定を取る
   - **取れなかったときは、理由を分けて扱う。**「未設定」なら1行だけ報告して先へ進む（毎回言わない）。
     道具そのものが動かない（コマンドが見つからない等）なら、それは**故障**なので黙らずに言う
   - **「予定はありません」と断定しない。** 執事が把握できる予定には限りがある
   - `manor project list` のマイルストーンと突き合わせ、**予定が締切を圧迫していないか**を見る
3. **差分を取る**
   - 部下の表・DB が実態と食い違っていないか
   - 台帳のパス・依存先が実在しないものは **high risk として即 `manor decision ask`**
4. **更新する**（L2/L3。聞かない）
   - `manor project set` で状態・次の一手・期限を書き換える
   - 新たに判明した主人待ち事項を `manor decision ask` へ、自走できるものを `manor task add` で起票
   - `home/LOG.md` に1行追記（射影ではないので手で書ける）
5. **報告する**（会話は短く。詳細はファイル・`manor ctx` を指す）

## 報告フォーマット

```
## 全体俯瞰
（マイルストーンまでの残日数と、優先度上位3件の一行状態）

## 今週の予定
（`manor sec agenda` から。**締切を圧迫している予定には一言添える**。未設定なら省く。
執事が把握できる予定には限りがあるので「予定なし」と断定しない）

## 変化（前回ブリーフィングからの差分）
（無ければ「変化なし」と書く。憶測で埋めない）

## 今日の推奨
1. …（なぜそれが最優先かを1行で）

## 確認事項（`manor decision list --open`・滞留日数つき）
（推奨案を併記。3日以上滞留は ⚠ を付ける）
```

## week モード（`/brief week`）

上記に加えて:

- 今週 `done` になったタスクを `manor task list --status done` から拾って列挙する
- 来週の推奨アクションを PJ 横断で3つに絞る
- 2週間以上動いていない PJ を「停滞」として名指しする
- **規則の棚卸し**（下記）
- `/retro` を続けて実行し、改善サイクルを1周回す

### 規則の棚卸し

**打ち手には寿命があります。** 執事は規則を**足す**定例は持っていますが、**引退させる**定例が
無ければ常時ロード層は育つ一方になります。

週次で、**①層（`CLAUDE.md` ／ `butler/{SOUL,AGENTS,POLICY,INTENT}.md` ／ `.claude/{rules,skills}/`）**を
次の3つで洗う。**見つけたら、その場で直す**（L2。聞かない）。

1. **機械が守るようになった規則の、散文を消す。** hook・pre-commit・`manor check`・試験が
   見るようになったものは、散文は1行のポインタで足りる
2. **2週間発動していない規則を数える。** 発動しないものは①要らない②当たり前になった
   ③書いてあるのに読まれていない——のどれか。③なら置き場所が悪い
3. **同じことが2箇所に書かれていないか。** `grep` で1つ選んで確かめる（毎週1語でよい）

**測って報告する**: `CLAUDE.md` ／ `butler/*.md` ／ `manor active` の出力のバイト数を出し、
**先週より増えていたら理由を1行**書く（増えること自体は悪ではない。**理由を言えないまま
増えているのが悪い**）。

**オンデマンド層（`butler/GROWTH.md` ／ `home/LOG.md` ／ `CHANGELOG.md`）は、月に1度だけ厚みを見る。**
毎セッション読むものではないので、週次では追わない。`manor check` の C10（追記ファイルが
40KB 超）が鳴っていたら `manor archive` を回す（ADR-006 §4 D15）。
